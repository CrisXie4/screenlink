# 无线连接指南

ScreenLink 支持两种无线模式，按场景选择：

| | 模式一：USB 引导切 WiFi（tcpip 5555） | 模式二：无线调试配对（Android 11+） |
|---|---|---|
| 前置条件 | 需要先插一次数据线 | 不需要数据线 |
| 加密 | 无（adb tcpip 明文） | TLS 加密（配对码派生密钥） |
| 稳定性 | 高（端口固定 5555） | 中（端口随机，息屏可能断开） |
| 适用场景 | 家里/办公室固定使用 | 不方便插线、临时投屏 |

## 模式一：USB 引导切 WiFi（推荐）

1. 手机开启 USB 调试，数据线连接电脑；
2. ScreenLink 识别到设备后，在设备操作里执行「切换到无线」（底层执行 `adb tcpip 5555`）；
3. 拔掉数据线，ScreenLink 会记住该设备的 WiFi 地址并自动重连（设置里的「拔线自动切 WiFi」）。

注意事项：
- 手机与电脑必须在**同一局域网**（同一路由器，或电脑开热点给手机）；
- 5555 模式是 adb 明文协议，**仅建议在可信网络使用**，公共 WiFi 下请用模式二；
- 部分 ROM 重启后会关闭 5555 监听，重新插线执行一次「切换到无线」即可。

## 模式二：无线调试配对（无需数据线）

前置：Android 11+，且手机「开发者选项 → 无线调试」可以打开。

1. 手机：设置 → 开发者选项 → 无线调试 → 开启；
2. 手机：点「使用配对码配对设备」，会显示一组 **IP:配对端口** 和 **6 位配对码**（弹窗存在期间有效，约 1 分钟）；
3. 电脑：ScreenLink 左侧栏「无线 → 扫描」，列表会出现「待配对」条目，点「配对」输入配对码；
   - 扫描不到时用「配对」按钮手动输入手机上显示的 IP:配对端口；
4. 配对成功后再扫描，会出现「可连接」条目（`_adb-tls-connect`），点「连接」即可。

注意：
- **配对码弹窗关闭即作废**，端口也会变化，重新获取即可；
- 配对是一次性的：配对成功后设备已信任电脑，以后直接「连接」；
- 手机端「无线调试」总开关关闭后所有连接断开，重开后需要重新连接（设备仍信任，无需重新配对）。

## 已知行为与坑（真机验证结论）

- **息屏断连**：部分机型（尤其 HyperOS/MIUI）息屏或锁屏后会断开无线调试的 TLS 连接。亮屏后 ScreenLink 重连即可；长时间投屏建议保持亮屏或在开发者选项中开启「充电时屏幕不休眠」。
- **mDNS 残留记录**：手机重连 WiFi 或重开无线调试后端口会变，扫描列表里可能残留旧端口的「可连接」条目，连接会失败——重新扫描，或以手机当前弹窗显示的端口为准。
- **AP 隔离**：公司/酒店路由器常开启客户端隔离，手机和电脑互相 ping 不通，无线连接完全不可用。换热点或家用路由。
- **多网卡 / VPN**：电脑开 VPN 或多网卡时，mDNS 扫描可能走的不是手机所在网段。扫描不到时优先用手动输入 IP。
- **HyperOS/MIUI 无线传输**：小米系 ROM 在无线 adb 下 `adb push` 大文件偶发静默损坏（内容错乱无报错）。ScreenLink 已针对此调整传输路径；对大文件（>100MB）仍建议优先 USB。
- **防火墙**：ScreenLink 只主动出站连接（adb → 手机端口），Windows 防火墙默认放行出站，一般无需配置。若使用了第三方防火墙，放行 `adb.exe` 与 ScreenLink 即可。

## 排查决策树

```
扫描不到任何「待配对/可连接」
 ├─ 手机「无线调试」总开关没开？
 ├─ 电脑和手机不同网段？（手机看 IP 前三段是否与电脑一致）
 ├─ 路由器开了 AP 隔离？→ 换热点
 └─ 电脑多网卡/VPN？→ 用「配对/输入 IP」手动连

扫描得到但连接失败
 ├─ 端口是旧的（mDNS 残留）→ 重扫 / 看手机当前端口
 ├─ 手机端「无线调试」刚重开 → 重新点连接
 └─ 之前从未配对成功 → 先走配对流程

能连接但频繁断
 ├─ 息屏导致 → 保持亮屏 / 充电时不休眠
 ├─ 信号弱 → 靠近路由器
 └─ HyperOS 省电杀后台 → 伴侣 App + Shizuku shell agent（见 low-end.md）
```
