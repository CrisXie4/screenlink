# 低端手机 / 老电脑适配指南

ScreenLink 的目标是在 2015 年级的电脑和入门级手机上依然可用。本文说明各组件的最低要求、降级路径，以及遇到性能问题时的调优方法。

## 电脑侧要求

| 组件 | 最低要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 1803+ | 更老的系统不保证 WebView2 可用 |
| WebView2 运行时 | Edge 94+（2021 年后随系统更新自带） | 视频解码依赖 WebCodecs |
| 内存 | 空闲占用 < 150MB | 应用自身不含解码缓冲 |
| USB | 任意 USB 2.0 口 | 老电脑可能缺 ADB 驱动，见下文 |

### WebCodecs 检测

点击「连接」时如果 WebView2 过旧（没有 `VideoDecoder`），ScreenLink 会直接给出提示并附上 WebView2 Runtime 的下载地址，不会出现卡在"连接中"无反馈的情况。修复方式：安装最新 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 后重启应用。

### 画质预设（老电脑必读）

设置 → 「画质预设」三档，点击后保存，下次投屏生效：

| 预设 | 分辨率上限 | 码率 | 帧率 | 关键帧间隔 | 适合 |
|---|---|---|---|---|---|
| 流畅 | 1280px | 4 Mbps | 30 fps | 4 秒 | 老电脑、低端手机、WiFi 信号弱 |
| 均衡 | 1600px | 8 Mbps | 60 fps | 2 秒 | 大多数场景（推荐） |
| 高清 | 1920px | 16 Mbps | 60 fps | 1 秒 | 高配设备、需要看清小字 |

参数含义与取舍：
- **分辨率上限**：手机画面会降采样到该边长再编码，直接决定手机端编码器与电脑端解码器的负载，是性能的第一杠杆；
- **码率**：决定画面清晰度与传输带宽。WiFi 投屏卡顿时优先降码率而不是降分辨率；
- **帧率**：办公/文档场景 30fps 完全够用；游戏投屏才需要 60；
- **关键帧间隔**：间隔越大，手机端编码负担越小（关键帧最贵）、越省电；代价是画面出错后恢复更慢、中途接入等待更久。低端设备的「流畅」预设放宽到 4 秒。

## 老电脑 USB 驱动

Win7 / 早期 Win10 上手机插 USB 后 `adb devices` 完全看不到设备，通常是 ADB 接口没有绑定驱动（设备管理器黄色叹号）。

ScreenLink 会自动检测这种情况：设备栏出现「USB 驱动异常」提示卡，点**「一键安装驱动」**即可——自动下载 Google 官方 USB Driver 并提权安装（UAC 确认一次），完成后重新插拔数据线。

手动方式（备用）：设备管理器 → 找到带叹号的设备 → 更新驱动 → 浏览计算机 → 从列表选择「WinUSB 设备」或安装 Google USB Driver。

## 低端手机

- 编码压力是主要瓶颈：老 SoC 的硬件编码器性能弱，高分辨率高帧率会掉帧、发热、降频。用「流畅」预设；
- 若画面完全出不来（黑屏但有连接）：该机型编码器对参数敏感，把分辨率降到 1080、帧率降到 30 再试；
- 传输大文件优先 USB（无线场景见 [wireless.md](wireless.md) 的 HyperOS 说明）。

## 后台保活（MIUI / HyperOS 冻结问题）

小米系 ROM 用 cgroup freezer 冻结后台应用，普通 Doze 白名单对它无效——伴侣 App 切后台就会被冻结，导致无线通道断开。ScreenLink 伴侣 App 的方案是 **Shizuku shell agent**：以 shell uid 运行的进程不受用户应用冻结策略影响（与 GKD 同款机制）。

启用方式：手机安装伴侣 App → 配对 Shizuku → 打开「shell agent」开关。之后投屏、文件传输、通知转发都不再受应用后台冻结影响。

## 性能问题排查顺序

```
投屏卡顿
 ├─ WiFi 还是 USB？WiFi 卡 → 降码率；USB 卡 → 降分辨率
 ├─ 看 UI 顶部 fps：fps 低 = 手机端编码跟不上（降分辨率/帧率）
 │                  fps 正常但画面延迟 = 解码/渲染链路（关掉其他大程序）
 └─ CPU 占用高 → 选「流畅」预设（30fps + 4s 关键帧）

连接就断
 ├─ 老电脑 → 查 USB 驱动（见上文）
 ├─ 无线 → 见 wireless.md 排查决策树
 └─ 手机后台被杀 → 伴侣 App + Shizuku shell agent
```
